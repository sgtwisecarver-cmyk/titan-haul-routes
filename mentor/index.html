The problem

Every mentor grades to a different standard

The Mentor Certification Manual already defines how a trainee should be evaluated. What we have never had is a way to confirm a mentor knows that standard before they start grading someone. The same behavior earns a Y from one mentor and an N from another — not through dishonesty, but because two reasonable people drew the line in different places. When that happens across a yard full of mentors, a trainee’s file stops meaning anything, and EHS is signing off on paperwork it cannot actually verify.

What this program adds

No driver is assigned an SSE until their record reads Certified Mentor. A mentor whose annual refresher is past due does not get a new trainee — the manual already says so; now the system enforces it.

Certification

Passing the quizzes is not the certificate

A written test proves a mentor can recognize a bad grade. It does not prove they will give one to a man they have hauled with for six years. So the last step stays human: EHS observes the candidate grading a real shift and compares their marks against its own. Disagreement on a rubric call is the point of the exercise — that gap is exactly what the program exists to close.

Program rules

Set by EHS, enforceable from day one

These four were the open questions when the program was designed. All four are now decided, which means the gate can be switched on as soon as the SharePoint build is standing.

ELIGIBILITY

Nomination, not tenure

No minimum time in service. A driver becomes eligible when their yard manager nominates them and both HR and Safety approve. Mentoring is a separate skill from driving, and this keeps the gate on judgment rather than seniority.

RETAKES

Three attempts per module

A candidate who cannot pass a module in three tries sits down with EHS before a fourth. Wrong answers return the reasoning, so a retake teaches rather than just re-scores.

EXISTING MENTORS

No grandfather clause

Every current mentor certifies on the same terms as a new one. Grandfathering would have left in place the exact grading inconsistency the program was built to correct.

RECORDS

EHS owns it

EHS owns the SharePoint site, the certification list, and the expiry alerts. HR holds read access. Retention matches the standard already applied to driver qualification files.
